# Skill: Accessibility Reviewer

Use esta skill quando a tarefa envolver tela, formulário, botão, navegação, contraste, leitura, usabilidade, desktop, mobile ou painel admin.

## Objetivo

Garantir que a interface seja mais acessível, legível e utilizável por diferentes usuários.

## Sempre avaliar

- Contraste de texto e fundo
- Tamanho de fonte
- Labels de inputs
- Estados de foco
- Navegação por teclado
- Ordem lógica dos elementos
- Botões com nomes claros
- Ícones com texto ou aria-label
- Mensagens de erro claras
- Área de toque em mobile
- Uso correto de aria quando necessário
- Evitar esconder foco ativo
- Evitar conteúdo inacessível em modais

## Antes de alterar

Responder com:

1. Problemas de acessibilidade encontrados
2. Severidade
3. Arquivos prováveis
4. Correções recomendadas
5. Validação prevista

## Regras

- Não remover foco visível.
- Não usar apenas cor para indicar estado.
- Não deixar botão sem texto acessível.
- Não esconder elemento focado com aria-hidden.
