# Skill: Design System Guardian

Use esta skill para preservar a identidade visual do projeto.

## Objetivo

Garantir que qualquer melhoria visual respeite marca, cores, componentes, ícones, tom visual e padrões já existentes.

## Sempre verificar

- Cores principais
- Tipografia
- Border radius
- Sombras
- Cards
- Botões
- Inputs
- Ícones
- Logo
- Personagens/mascotes
- Tokens de tema
- Componentes reutilizáveis
- Consistência entre telas

## Regras

- Não remover identidade visual existente.
- Não substituir cores principais sem aprovação.
- Não remover logo, robô, estrela ou elementos de marca.
- Preferir evoluir o design atual em vez de criar outro estilo do zero.
- Reutilizar componentes existentes quando possível.
- Se precisar criar padrão novo, justificar antes.
