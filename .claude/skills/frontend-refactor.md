# Skill: Frontend Refactor

Use esta skill quando for necessário melhorar código de tela, componentes, estilos, responsividade ou estrutura frontend.

## Objetivo

Melhorar a implementação sem quebrar comportamento existente.

## Sempre avaliar

- Componentes grandes demais
- Duplicação de layout
- CSS/SCSS repetido
- Responsividade
- Estados de loading
- Estados de erro
- Reuso de componentes
- Nomes de variáveis e funções
- Separação entre apresentação e lógica
- Chamadas duplicadas de API
- Re-renderizações desnecessárias

## Antes de alterar

Responder com:

1. Arquivos envolvidos
2. Componentes impactados
3. Riscos
4. Plano pequeno e seguro
5. Validação prevista

## Regras

- Não reescrever tudo sem necessidade.
- Preferir alterações pequenas.
- Preservar comportamento atual.
- Não remover funcionalidades.
- Não mudar contrato de API sem necessidade.
- Validar typecheck depois.
