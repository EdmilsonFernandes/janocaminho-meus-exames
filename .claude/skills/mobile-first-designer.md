# Skill: Mobile First Designer

Use esta skill quando a tela precisa funcionar bem em celular, APK, PWA, web mobile ou tablet.

## Objetivo

Garantir que a interface seja confortável, legível e funcional em telas pequenas.

## Sempre avaliar

- Conteúdo cortado
- Scroll vertical
- Overflow horizontal
- Cards muito grandes
- Botões pequenos
- Área de toque mínima
- Bottom navigation
- Header fixo
- Safe area
- Espaço para teclado aberto
- Textos longos
- Imagens pesadas
- Layout em 360px, 390px e 430px de largura

## Breakpoints mínimos

Validar ou considerar:

- 360x740
- 390x844
- 430x932
- 768x1024
- 1366x768

## Regras

- Priorizar uma ação principal por tela.
- Evitar cards gigantes.
- Evitar texto demais no primeiro bloco.
- Usar hierarquia clara.
- Garantir que o usuário consiga tocar nos botões facilmente.
- Não deixar conteúdo importante fora da área visível.
