# Skill: UI/UX Reviewer

Use esta skill quando a tarefa envolver tela, layout, mobile, web, desktop, painel admin, app, responsividade ou experiência visual.

## Objetivo

Analisar a tela como experiência de usuário e propor melhorias práticas sem perder a identidade visual do projeto.

## Sempre avaliar

- Hierarquia visual
- Clareza do objetivo da tela
- Ação principal
- Excesso de informação
- Espaçamento
- Tamanho de fonte
- Contraste
- Estados vazios
- Estados de loading
- Estados de erro
- Responsividade
- Mobile first
- Acessibilidade básica
- Consistência com o design system

## Antes de alterar código

Responder com:

1. Problemas encontrados
2. Melhorias propostas
3. Arquivos prováveis
4. Riscos
5. Plano de alteração
6. Validação prevista

## Regras

- Não remover identidade visual.
- Não alterar comportamento sem necessidade.
- Não criar layout genérico.
- Não quebrar mobile.
- Não esconder informação importante.
- Não alterar cores principais sem justificativa.
