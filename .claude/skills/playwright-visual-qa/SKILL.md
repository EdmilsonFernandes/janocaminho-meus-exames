# Skill: Playwright Visual QA

Use esta skill quando a tarefa envolver validação visual, mobile, desktop, fluxo de tela, layout quebrado ou responsividade.

## Objetivo

Validar a interface após alterações usando navegador real.

## Sempre testar

- Desktop
- Mobile pequeno
- Mobile médio
- Tablet quando fizer sentido
- Estados de loading
- Estados vazios
- Estados de erro
- Scroll
- Botões principais
- Menus
- Modal
- Inputs
- Navegação entre telas

## Viewports recomendados

- 360x740
- 390x844
- 430x932
- 768x1024
- 1366x768

## Verificações

- Não há overflow horizontal.
- Não há tela cortada.
- Botões são clicáveis.
- Textos são legíveis.
- Cards não quebram.
- Header e footer não escondem conteúdo.
- Layout não fica branco.
- Fluxo principal funciona.

## Resultado esperado

Ao final, informar:

1. Viewports testados
2. Fluxos testados
3. Problemas encontrados
4. Correções feitas ou pendentes
5. Evidências, quando possível
